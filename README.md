# home2025

A modern personal homepage built with vanilla HTML, CSS, and JavaScript.
I created a new one since the old one is almost 5 years old.

## Overview

This web page is a portfolio and profile website, including sections for skills, experiences, projects, and profile links.
The design created with pure CSS is clean and responsive, with smooth animations and interactive UI elements.

## Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**

No frameworks or libraries are used: just pure web technologies.

## Features

- **Animated Intro**: Welcoming section with background image and animated text.
- **Menu Bar**: Sticky navigation with icons and interactive glass-like effect.
- **Skills & Experiences**: Lists of my skills and experiences.
- **Projects**: Lists of my works with clickable icons with detailed description views.
- **Profiles**: Quick links to my social and contact profiles.

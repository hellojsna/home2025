Hello, I am Jisung Na, an iOS app / web developer.

Project Peri is a project that has a lot of meaning to me.

As the software gifted class activities at Imjin Elementary School, it's the result of learning and applying the process of identifying social issues and proposing solutions.

It's the first project I've worked on from planning to completion, and the first project I collaborated with others.

Using Arduino, I created a device that has fine dust sensor and air purifier, and a program using Visual Basic .NET for viewing fine dust information on a PC via serial communication.

This project sparked my interest in becoming a software developer, and I decided to pursue a career as a software developer.

TodayLunch is the first iOS app I launched on App Store

Developed with SwiftUI, it was created based on the philosophy of "Want it? Make it!", designed for me to check the school lunch menu on Apple Watch.

Through this project, I learned the basics of SwiftUI and gained a deeper understanding of iOS app development.

Additionally, after the launch of the 4th generation of NEIS in 2023, I built my own DB and server to deal with unstable API and provide stable service.

TrainNet is a long-term project that has been in development since 2022, with the goal of creating a "Railway Platform for All."

Beyond a simple subway map, I aim to create a platform where users can easily access and share information.

Currently, I am testing some features by releasing beta versions of the station information and the prepaid transportation card balance reader.
